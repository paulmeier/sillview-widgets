# Transactions

The most recent transactions across all accounts.

- **Category:** Activity
- **Type:** `transactions` (first-party built-in)
- **License:** MIT

## Configuration

- `limit` (number | string): How many recent transactions to list (default 40).
- `accountId` (string): Restrict to a single account id; omit for all accounts.

This widget's implementation ships compiled into the sillview app. Installing it from the
marketplace simply makes it available to add to a dashboard.
